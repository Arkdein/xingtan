Google connection test

Checks whether 杏坛 · ClassroomBoard can create a Google Form in your Drive, publish it, and show students’ answers live. Nothing here is part of the app yet.

1 · Google Cloud client ID

Paste the OAuth client ID from Google Cloud (it ends in .apps.googleusercontent.com). It is not a secret. It is saved in this browser only.

2 · Run the test

Sign in with the account you would use in class (your iCON teacher account). The app asks only to create and edit the files it makes itself.

    3 · Answer on a phone

    Scan with a phone signed in to a student iCON account, and send a test answer. Then try a phone or browser that is not signed in to any school account.
