# 杏坛 · ClassroomBoard

**杏坛 (Xìngtán)**, the "apricot altar", is where Confucius is said to have taught his students (《庄子·渔父》). Ever since, it has stood for the classroom and for teaching.

A classroom display board in the spirit of Classroomscreen. It runs entirely in the browser and is hosted on GitHub Pages.
**All class lists and layouts stay in the teacher's own browser.** Nothing is uploaded, and there are no accounts or servers.

Closing a tool with **×** shows **Undo** for 8 seconds, which brings the tool back where it was, with everything in it. Text posts are saved for every board anyway (see [Text](#text-文字)). Lesson flow, Organiser, Thinking routine, Whiteboard and Sentence analysis keep their work on the board (see [Saved on this board](#saved-on-this-board-本白板已存)), and YouTube, Music, Images/ PDF, Share link and the Name picker's own list are kept on the board itself, so they come back even after that.

### Saved on this board 本白板已存

**Lesson flow**, **Organiser**, **Thinking routine**, **Whiteboard** and **Sentence analysis** keep what they hold on the board, so closing the tool doesn't lose it:
- Work is saved as you go (a moment after each change) and kept when the tool is closed. **Saved on this board** (📚 in the title bar) lists everything the tool has held on this board, newest first, with **+ New**. A new tool opens to the list, or straight to work when nothing is saved yet. One left blank isn't kept.
- **Rename** (✎), **copy** and **delete** (click twice, with **Undo** for 8 seconds). Lesson flow's **Make a copy** unticks everything for the next class; Organiser and Thinking routine have **Use again with no notes**. After a routine ends, **New routine** keeps the ended wall in the list and starts a new one. Whiteboard's **Make a copy** copies the pages. **Find** appears with seven or more items.
- An item open in another tool of the same kind on the board can't be opened or deleted there.
- The list lives on the board (`toolData[type].items`, see `js/widgets/saved.js`), so copies of the board, backups and shared board files carry it. Shared files clean saved thinking routines as they clean the open one: set-up only, no notes or names. Tools from before this change become the first saved item when the board is opened.

### Minimising a tool

**−** in a tool's title bar shrinks it to a small chip on the board, to make room without closing it. Closing a tool (✕) takes it off the board (with **Undo** for 8 seconds); minimising keeps it there, so a board can be set up before the lesson with tools tucked away until they're needed. A minimised tool keeps working.
- Minimised tools line up on a **shelf** down the left edge of the board, under the board name, each new one at the end. Chips that only show a tool's name are icon-only there, with the name on hover. When the shelf is full, the rest go under **… N more**, which lists them.
- **Reorder the shelf** by dragging a chip up or down it: the other chips slide apart to show where it will go. Or focus a chip (Tab) and press ↑ / ↓.
- **Drag** a chip off the shelf to put it anywhere on the board (for example the Timer beside a question); drag it back to the left edge to put it on the shelf again, at the place the gap shows. **Click** a chip's icon (or press Enter on it) to open the tool again at its old size and place.
- **Minimise all** (beside the board name) clears the board in one tap; **Open all** brings every tool back.
- Most chips show the tool's name. Some show what the tool is doing, with a button or two:

| Tool | Chip |
|---|---|
| Timer / Stopwatch | Time left (red in the last 10 seconds) and start / pause. The chip flashes when time is up. |
| Clock | The time |
| Text | The first line of its post (or *Text* when it shows the list of posts or the post is empty) |
| Lesson flow | The step the lesson is on (such as *2/5 · Pair work*) and **Next** |
| Traffic light | The three lights; tap one to change it |
| Work mode | The sign on show |
| Poll | Whether the poll is open, and how many have answered |
| Noise meter | The face, a level bar, and start / stop listening. The chip glows red when it's too loud. |
| Music | Play / pause and what is playing |
| Quotes | The quote on show (it keeps changing if the tool is set to change quotes by itself) |

- A YouTube video pauses when its tool is minimised. Music keeps playing. The Noise meter keeps listening, and its chip shows a stop button while it does.
- Each board remembers which tools are minimised, the order of its shelf and where any chips taken off it sit. The boards screen shows them as chips too.

### Customising the dock

Tap **Edit** at the right end of the dock to:
- **Reorder** tools by dragging them (or focus a tool and use the ← → keys).
- **Hide** a tool with **−**. Hidden tools stay one tap away under **More**.
- **Add a tool back** with **+**.
- Choose how many **Rows** the dock may use (1, 2 or 3; 2 to start with), switch to **Icons only (compact)**, or **Reset** to the original dock.

Tap **Done** or press Esc to finish. The dock layout is the same on every board in this browser and is included in backups.

Tool tiles are colour-coded by purpose: **blue** for time (Timer, Clock, Lesson flow), **apricot** for students (Name picker, Groups, Points, Poll), **green** for class signals (Noise meter, Traffic light, Work mode), **grey** for content and thinking (Thinking routine, Organiser, Text, Whiteboard, YouTube, Music, Images/ PDF, Share link, Quotes) and **plum** for language (Dictation, Character grid).

The dock puts up to **10 tools in a row** and wraps onto the next row, sharing the tools evenly between the rows. On a narrower screen it first puts its labels on two lines, then shows icons only. Tools that still don't fit go under **More** (listed under *No room in the dock*), so the dock never runs off the screen. Hover over an icon for its name.

### Hiding the dock

Tap the small tab on top of the dock (⌄) to **hide the dock** for a clean board, for example to project a question or a video. A **Tools 工具** tab stays at the bottom of the screen: tap it to bring the dock back. **D** on the keyboard does the same (when you aren't typing in a tool).

Each board remembers whether its dock is hidden, so a quiz board can open with the dock hidden while the main lesson board shows it. The dock floats over the board, so hiding or showing it never moves the tools on the board. A board copied or shared as a file keeps this setting.

## Boards

Each lesson or class can have its own **board**: its tools, text, timer settings and background.

- When the app opens, the **boards screen** greets the teacher (time of day and date, in English and 中文) and asks which board to open. The large **Continue where you left off** button reopens the last board in one tap. A reload reopens the board that window had open.
- **Boards** (top left) goes back to the boards screen. Click the board name for **board settings**: its name and background. The palette button (top right) opens the background settings directly.
- Boards **save automatically** as you work. The *Saved ✓* label next to the name shows the status. Closing the window never loses work, so there is no “Save?” prompt. The browser shows its own warning only if a save failed (for example, if storage is full).
- On the boards screen: **New board**, **Rename**, **Copy** (to reuse a lesson layout), **Share** and **Delete**.
- **⬇ Share** downloads one board as a file for a colleague to **⬆ Import**. Student names (picked names, groups) are left out, and class lists and points are never included.
- Class lists are shared by all boards.
- Opening one board in two windows keeps them in step. Different boards in different windows don't affect each other.
- A timer that ran out more than a minute earlier comes back reset, so an old board doesn't chime when it opens.

## Backgrounds

Each board has its own background, set in **board settings** (click the board name, or the palette button):

- **Colours:** eight presets or any custom colour.
- **Library:** images bundled with the app, in four sets: Chinese paintings (中国画), Nature (自然), Singapore (新加坡) and Festive (节庆). Every one is public domain or CC0; credits are listed under [Image credits](#image-credits) and shown in the picker. They work offline once viewed.
- **Upload:** any JPG, PNG or WebP. It is resized to screen size (about 1920 px) and kept in this browser's IndexedDB. Uploaded images can be reused on other boards and deleted from the Upload tab. Deleting the last board that uses one frees its space.
- **Image brightness** lightens or darkens an image so tools and the top bar stay easy to read. The corner controls switch between light and dark automatically.
- A full backup includes uploaded images in use. **Share** files never do: a shared board with an uploaded image arrives with a plain colour instead. Library images are kept, because every copy of the app has them.

## Thinking routines 思维常规

Routines from Project Zero's *Making Thinking Visible* (Ritchhart, Church & Morrison):

- **Core 核心:** See · Think · Wonder 看·想·疑, Think · Puzzle · Explore 想·疑·探, Claim · Support · Question 主张·支持·质疑
- **Connections 联系:** Connect · Extend · Challenge 联系·拓展·挑战, Headlines 新闻标题, I used to think… Now I think… 以前我认为……现在我认为……
- **Perspectives 视角:** Compass Points 指南针, Circle of Viewpoints 观点圈 (students pick from the teacher's viewpoints), Tug of War 拔河 (students place themselves on a 5-point line between two sides)
- **Custom 自定义:** teachers write their own steps and sentence starters. Custom routines are shared by all boards and included in backups, but not in shared board files: a colleague who opens a board that used one gets See · Think · Wonder instead, with a note saying so.

Each run chooses its language (English, 中文 or both) and whether students' names are **hidden on screen** (kept in the Sheet), **shown**, or **not asked**.

- **Prompt** view shows the routine's steps and sentence starters in large type, with a QR code when students answer on devices.
- **Wall** view collects answers as sticky notes, one column per step. Drag notes to regroup them, **star** the ones to discuss, and **hide** any that shouldn't be on screen. The teacher or a scribe can type notes too, so the routine also works with no devices.
- **Start with student devices** (needs Google, below) makes and publishes a Google Form for this run and shows its QR code. Answers arrive about every 5 seconds.
- **End** stops the form taking answers and saves everything to the class's Google Sheet, one tab per run. If the Google sign-in has run out, it asks to sign in again first; without it, the run ends and the form is closed as soon as Google is next connected. Shared board files keep the routine set-up but never students' answers.
- **New routine** clears the wall, so it asks first (click twice) unless the run was saved to Sheets.
- Closing the tool during a run on devices (once Undo has gone), or deleting its board, closes the form too. A copied board starts with no run.

The stems are in `js/routines.js`.

## Poll 投票

Three modes, each with its own question (a default is filled in if the box is left empty) and language (English, 中文 or both):

- **Scale 1–5 (量表):** a Likert scale with the teacher's own end labels (for example *1 = Not at all*, *5 = Very much*). Shows a bar for each number, the share of answers and the average.
- **Mood meter (情绪象限):** four zones by energy and pleasantness: **Red** 红 (high energy, unpleasant: angry, worried, stressed), **Yellow** 黄 (high energy, pleasant: excited, happy, proud), **Blue** 蓝 (low energy, unpleasant: sad, tired, bored) and **Green** 绿 (low energy, pleasant: calm, relaxed, content). On devices, students can also give one word for how they feel (optional); the words show in their zone.
- **Word cloud (词云):** one word or short phrase each. Answers are counted whole by default (the same spelling counts together, ignoring capitals and end punctuation). **Split words** counts the separate words instead, using the browser's own word splitter for Chinese and leaving out little words (的、了、是, the, a…).

Two ways to collect answers:

- **Collect on devices** (needs the [Google connection](#google-connection)): students scan the QR code and answer a Google Form. **Each class has one poll form that every poll reuses**: the app rewrites its question each time, so the link never changes and a QR code printed from **QR → Print the QR code** works for every poll. When no poll is running, the form says it isn't taking answers. Answers arrive about every 5 seconds.
- **Count hands** (no devices): for Scale 1–5, students show 1–5 fingers (fist-to-five); for the Mood meter, they point to a zone. Tap a bar or zone to add one, **−** to take one away, **Reset** to start again. For a Word cloud this is **Type answers in**: the teacher or a scribe types what students call out.

During a poll:

- **Results stay hidden** until **Show results** (devices), so students don't just follow the first answers. The screen shows the question, the QR code and how many have answered. Counting hands starts with results showing.
- **Names:** **Anonymous** (the default; the form doesn't ask) or **Ask names (Sheet only)**: names go to the Google Sheet and are never shown on the board.
- **Word cloud moderation:** click a word to hide it. Common rude words in English, Singlish and Chinese are hidden automatically. **n hidden** lists hidden words, shown masked (s•••), and a click puts one back. Rude feeling words in the Mood meter are hidden the same way, with the same list to put them back.
- **End** stops the form taking answers and keeps the result in the class's **Past results**. If the Google sign-in has run out, it asks to sign in again first; without it, the form is closed as soon as Google is next connected. Closing the tool during a device poll (once Undo has gone), or deleting its board, closes the form too, though only **End** keeps the result. With Google connected it is also saved to the class's Google Sheet (one tab per poll, with each answer listed). **CSV** downloads the poll as a spreadsheet.

**Past results** (历史记录) lists finished polls per class, newest first: tap one to see its chart again. **Download all (CSV)** gives one row per poll (date, question, number of answers, average, counts per number or zone, top words), useful for seeing how confidence or mood changes over a unit. Past results keep totals and words only, never names. They are part of full backups but never of shared board files, which keep only the poll's set-up.

### Google connection

Optional, and only when the teacher clicks **Connect Google** (also in ⚙️ Settings). The browser signs in with Google directly; there is still no server.

- The app asks only for Google's `drive.file` permission (the files it creates itself) and the account's email. It cannot see anything else in the teacher's Drive.
- Forms and Sheets are made in a **杏坛 ClassroomBoard** folder in the teacher's Drive and stay there. Thinking routines make a new form for each run; polls reuse one form per class. Each class has one Sheet, *杏坛 · class · Thinking routines & polls 思维常规与投票* (classes that already had a Sheet keep it).
- The sign-in lasts about an hour and is kept in the open tab only. **Reconnect** renews it.
- Students never sign in to 杏坛. The forms are open to anyone with the link.
- See [privacy.html](privacy.html).

## Points

- **Points belong to the class, not the board.** Every board showing 2E1 shows 2E1's running totals, so a new or copied lesson board picks up where the last lesson left off.
- **Tap a name** to mark that student absent for today. Absent students are greyed out and skipped by **+ All** / **− All**. The marks clear the next day.
- **↶ Undo** reverses the latest change, including a whole-class one (up to 20 of today's changes).
- **Sort:** *Class order* (the default every time the tool opens), *A–Z*, or *Top*. Rows never move while you tap; tap *Top* again to re-sort.
- Points can go below zero.
- **⋯ menu:** set a **goal bar**, **download the log** as a CSV (one row per student, one column per day, plus the running total) and **reset points to 0** for a new term (the log is kept; the goal bar goes back to the start).
- **Goal bar** (for younger learners): a **class goal** (one shared track; every point anyone earns moves it on) or a **student goal** (a track in every row). Counting starts from zero when the goal is saved; changing only the marker, chime or reward keeps everyone's place. Classes that had the older class-total goal keep their place.
  - **Markers** (drawn for 杏坛, each with its own finish): star → trophy, rocket → moon, ship → island, plane → cloud, car → finish flag, train → station, rabbit → carrot, bee → flower, dragon → pearl (龙珠), panda → bamboo. With student goals, any student can have their own marker.
  - **Chimes** (made in the browser, no sound files): bell, xylophone, fanfare, gong (锣), sparkle, wind chimes. Tap one in settings to hear it. Optional short cues at ¼, ½ and ¾ of the way. 🔊 in the tool mutes all sounds for that class.
  - **At the goal:** the chime plays once, with a banner (and the **reward**, if one is set) and confetti (none when the computer asks for reduced motion). A class goal waits, full, for **Next round**. A student's marker waits a moment at the finish, then starts the next round with a badge (the finish picture ×2, ×3…).
  - **Undo** moves markers back, badges included, but never replays a chime. Absent students' tracks are dimmed.
  - With a class goal, ⤢ shows only the bar, sized for the back row. The minimised chip shows the class bar, or the number of badges in the class.
- Points are matched by name. Editing a student's name in the class list starts them at 0; removing a name and adding it back brings its points back. Deleting a class deletes its points.

## YouTube

- **Adding a video:** tap **Add video** and paste a link from YouTube (youtube.com, youtu.be, Shorts and links with a start time all work). Then **Play now**, or **Save** it to this board for later.
- **Keyword search** (optional) needs a free YouTube Data API key. Each teacher adds their own under **⋯ → YouTube settings**, which has a step-by-step guide (about 5 minutes, once). A key allows about 100 searches a day; the count restarts at midnight California time. Results use YouTube's SafeSearch (strict) and only show videos that are allowed to play on other websites. Without a key, typing keywords offers **Search on YouTube** in a new tab, so the teacher can copy a link back.
- **Saved videos belong to the board, not the tool.** Closing the YouTube tool keeps the list, and adding the tool again brings it back. Copying, sharing or backing up the board includes the list. The tool opens to its list, and nothing plays until the teacher picks a video. Drag the ⠿ handle to put videos in lesson order (or focus it and use ↑ ↓).
- **✎ Edit** sets a **clip** (start and stop times, such as 1:20 to 3:45), a **teacher note** (for example “Pause at 2:10 for See–Think–Wonder”, shown in the list only) and the title. While watching a saved video, **✂ Clip → Start here / Stop here** sets the times from the video itself.
- **Fewer distractions:** a cover hides the player until **Play** is pressed. At the clip's stop time, or the end of the video, the video is covered with **Replay** and **Back to list**, so YouTube's suggested videos don't show. **YouTube settings → Cover the video when it's paused** also hides YouTube's paused screen (off by default, so a paused frame can be discussed).
- If an uploader doesn't allow their video on other websites, the tool says so and offers **Open on YouTube**.
- Videos need the internet, and play in YouTube's privacy-enhanced player (`youtube-nocookie.com`). YouTube's own ads may still appear.

## Music 音乐

- **Adding music:** tap **Add music** and choose from three places:
  - **Music library 音乐库:** six pieces composed for the app, in three sets: **Calm 安静** (Morning Garden 晨园, Bamboo Breeze 竹风), **Focus 专注** (Soft Rain 细雨, Quiet Study 静读) and **Festive 节庆** (Spring Lanterns 春灯, Celebration 欢庆). Tap a track's tile to listen before adding it. Each track is downloaded the first time it plays and works offline after that. They are free to use in class: see [Music credits](#music-credits).
  - **Your files 自己的文件:** MP3, M4A, WAV or OGG files from the computer (**Choose music files**, or drag them onto the tool), up to 40 MB each. They are kept in this browser, like uploaded pictures. **Already on this computer** lists files added on other boards, so they can be reused without adding them again.
  - **Spotify:** paste a playlist, album or song link (in Spotify: **Share → Copy link**). The board shows Spotify's own player; press play in it. Whole songs play when the teacher is signed in to **Spotify Premium** in the same browser on a laptop or desktop; otherwise Spotify plays 30-second previews. **Open in Spotify** plays it in the Spotify app instead. The app doesn't sign in to Spotify or see the teacher's account. Short `spotify.link` addresses need opening first, so the full `open.spotify.com` address can be copied.
- **The list belongs to the board, not the tool.** Closing the Music tool keeps it, and adding the tool again brings it back. Drag the ⠿ handle to put the music in order (or focus it and use ↑ ↓). **✎** sets a title and a **teacher note** (for example “For silent reading”), shown in the list only. Nothing plays until the teacher presses play.
- **Playing:** the bar at the bottom has play / pause, the position (click or drag to jump; ← → move 10 seconds), **next**, **repeat** (the whole list, or just this track), **Fade out** (lowers the music over 3 seconds, then pauses) and the volume. Each board remembers its volume. Music stops when the board is closed.
- **Play with the Timer** (off to start with, set for each board): when a Timer or stopwatch on the board starts, the music starts too, rising gently from silence; pausing the Timer pauses the music; when time is up or the Timer is reset, the music fades out and goes back to the beginning. It plays the track last played on the board, or the first one in the list. A small ⌛ beside the track's name shows the link is on. The app doesn't start Spotify by itself (Spotify's player plays only previews when a page starts it), so with a Spotify playlist the teacher presses play in Spotify's player; the Timer still pauses it and stops it when time is up.
- **Minimise (−)** shrinks the tool to a chip (see [Minimising a tool](#minimising-a-tool)). The music keeps playing, and **Play with the Timer** still works. The chip shows play / pause and what is playing, with moving bars while it plays.
- **Sharing and backups:** copying a board copies its music list. Full backups include the music files in use. Shared board files keep library tracks and Spotify links but leave the teacher's own music files out, so a colleague adds their own.

## Images/ PDF

- **Adding pictures:** **Upload pictures or PDFs** (several at once), drag pictures or PDFs onto the tool (from the computer or from a web page), copy a picture or screenshot and press **Ctrl+V** (⌘V on a Mac), paste a picture's web address, or **Take a photo** with the laptop camera or a visualiser (pick the camera if there is more than one).
- **PDFs:** each page becomes a picture (2400 px on the long side, so text stays sharp when zoomed), grouped under the PDF's name in the list. For a PDF of more than one page the teacher picks **All pages** or types some, such as `1-3, 7`. Next / back steps through the pages, then on to the next item. Pages can't be searched and links in the PDF don't work, because they are pictures. A page takes about 0.2–0.4 MB. Password-protected PDFs need saving without the password first.
- Pictures are shrunk to screen size (at most 1920 px) and kept in this browser. Screenshots and diagrams stay sharp as PNG; photos are stored as JPEG.
- If a website doesn't allow its picture to be copied, it is saved as a **web link** instead: it shows from the web, so it needs the internet and isn't in backups.
- **Pictures belong to the board, not the tool.** Closing the Images tool keeps them. The tool opens to its list, and nothing shows until the teacher picks a picture. Drag the ⠿ handle to put them in lesson order (or focus it and use ↑ ↓).
- **✎** adds a **caption**, shown under the picture for the class, and a **teacher note**, shown in the list only.
- **Showing a picture:**
  - **Move and zoom:** scroll, pinch, double-click or use − / fit / fit width / +. Once zoomed in, scrolling moves around the picture (hold Ctrl or ⌘ to keep zooming), and so does dragging. **Fit width** suits tall PDF pages: it fills the width from the top.
  - **Pen** and **highlighter** in a few colours, **rub out** one line, **undo** and **clear**.
  - **Type text** (Aa): click where the text should go and type, for example answers on a worksheet. Enter starts a new line, A− / A+ change the size, the colours change its colour, the ⠿ handle moves it and × deletes it. Click away or press Esc to finish.
  - Drawings and text are saved with each picture or page until cleared.
  - **Reveal:** covers the picture with 2×2, 3×3 or 4×4 numbered tiles; tap a tile to uncover it (tap again to cover it), or **Show all** / **Cover all**.
  - **Next / back** with the side arrows, the ← → keys, or a presentation clicker (Page Up / Page Down). **Slideshow** starts from the first picture.
  - **Full screen** for the picture, its caption and the tools.
- **Sharing:** a shared board file includes the board's pictures (so it can be a few MB). Copying a board shares the same stored pictures; a picture is deleted from the browser only when no board uses it any more.

## Lesson flow 课堂流程

- A new Lesson flow opens ready to type in: an optional **lesson title**, **learning intentions** (“We are learning to…”), **success criteria** (“I can…”) and the **steps**, one per line. **Done** shows it on the board; the ✎ button edits it again. Ticks stay on lines that are still there.
- **Next** ticks off the step that is on now and moves to the next one not yet ticked; **Back** goes back a step. Click a step to make it the current one, or its number to tick it on or off. ↺ unticks everything for the next class.
- **List** shows every step with **Now** and **Next** labels. **Now / Next** shows just the current step, large, with the next one under it and the learning intentions at the top.
- Students (or the teacher) tick the **success criteria** during the plenary.
- **EN / 中文 / Both** sets the language of the headings. It is kept on the board, so each lesson board has its own flow.

## Organiser 思维导图

- Choose a layout: **T-chart**, **Venn diagram**, **Frayer model**, **KWL chart**, **5W1H** (六何法), **cause and effect**, **sequence**, **story mountain** (故事山), **concept web**, or **my own columns** (2 to 6, named by the teacher).
- Type a note into **+ Add a note** in any part and press Enter (Shift+Enter for a new line). The teacher or a student scribe types; there is no student-device version yet.
- Drag notes between parts. Hover over a note to **star**, **edit** (or double-click), **hide** or **delete** it. Hidden notes can be shown again from the link under the organiser.
- Add a **topic** or question at the top; the Frayer model and concept web show it in the middle.
- ✎ renames the parts (English and Chinese names); **EN / 中文 / Both** chooses which show. ⊞ chooses another layout and keeps the notes (notes in parts that no longer exist move to the first part). 🗑 removes every note (click twice).

## Whiteboard 画板

- **Paper:** blank, **田字格**, **米字格**, **拼音田字格** (a pinyin band above each row of boxes), **four lines** (四线三格, for pinyin or English handwriting, with a red base line), **lined**, **squares** or **dots**, each in three sizes (S, M, L). Each page has its own paper.
- **Pen** (four colours, thin or thick), **highlighter**, **type text** (click where it should go; A− / A+ for size), **rub out** a line or text, **undo** the last pen or highlighter line (also Ctrl+Z) and **clear** the page.
- **Pages:** + adds a page after this one with the same paper; ‹ › (or ← →, or a presentation clicker) move between pages; 🗑 deletes a page. Up to 30 pages.
- **Full screen** for the page and its tools. Pages are saved with the board, and go into shared board files.

## Text 文字

- **Saved posts (文稿):** everything typed in a Text tool is a post. Posts are saved as you type (a moment after you stop, and when you click away) and stay saved when the tool is closed. They are shared by every board in this browser, so “Homework” or “Success criteria” can go up in any lesson.
- **Opening the tool** shows the saved posts, last edited first, with the first line as the title, the next lines underneath and when the post was last changed. Click a post to show it, or **+ New post**. A new Text tool goes straight to a new post when there are no saved posts yet. With seven or more posts, **Find a post** filters the list.
- **All posts** (📚, the first button on the formatting bar) goes back to the list. A post with no text is not kept.
- **Make a copy** (⧉) starts a new post from an old one, for example last week's homework to change. A post open on two boards is the same post: a change on one board shows on the other, so make a copy to adapt it.
- **Delete** (🗑, click twice) deletes a post from the list, with **Undo** for 8 seconds. A post open in another Text tool on the same board can't be opened or deleted until that tool shows something else. Deleting a post that is also open on another board takes it off that board too (its Text tool shows the list).
- Each post keeps its own formatting, text size and background colour.
- **Tables:** **Insert table** on the formatting bar (rows, columns, **Header row** on or off). **Tab** / **Shift+Tab** move between cells; Tab in the last cell adds a row. With the cursor in a table the same button opens **Table tools**: add a row above or below, a column left or right, delete a row or column, header row on or off, **Delete table** (click twice). Formatting works inside cells. Pasted tables (Word, Google Docs, spreadsheets) stay as tables, rebuilt by `richtext.js` with no attributes: merged cells are split into empty cells, a table inside a cell becomes lines of text, and tables are capped at 40 rows and 12 columns. In the list of posts, each table row is one line with its cells joined by “ · ”.
- **Backups and sharing:** posts go into full backups. A shared board file carries the posts its Text tools show, and they are added to the colleague's list. Text tools from before saved posts become posts the first time the list is opened.

## Share link 分享链接

- **Add a link:** paste a web address (a Padlet, Google Form, Slido, reading…) and, if you like, a label such as “Exit ticket 课后反思”. The tool shows a large QR code, the label, and the address without `https://` for students who type it in.
- Click the QR code to show it even larger. **Copy** puts the address on the clipboard; **Open** opens it in a new tab.
- **Each board keeps its own links** (they come back when the tool is added again and go into shared board files). With more than one, choose which shows from the list at the top; **+** adds another, ✎ edits and 🗑 removes one.
- The QR code is made in the browser; nothing is sent anywhere. Long addresses make dense codes that are harder to scan from the back of the room, so a short link (such as bit.ly) helps.

## Dictation 听写

- **Word lists** are shared by every board in this browser, so one list can serve several classes. Pick one at the top of the tool, or **+ New word list**. Each board remembers which list it showed last. Lists go into full backups, and a shared board file carries a copy of its list.
- **Adding words:** type or paste them, one per line or separated by commas or 、. Chinese words get their **pinyin** straight away (worked out in the app, so it works offline; 一 and 不 are given in their dictionary tones). Edit any pinyin that needs it. A list's language (中文, English, Melayu, தமிழ்) decides how its words are read; Chinese characters are always read in Mandarin.
- **Looking words up** (needs the internet; only the word is sent):
  - **English** words: meanings, an example sentence or two, the pronunciation and often a recording, from the [Free Dictionary API](https://dictionaryapi.dev/) (from Wiktionary, CC BY-SA 3.0).
  - **Chinese** words: meanings and examples from [萌典](https://www.moedict.tw/), which serves Taiwan's Ministry of Education 《重編國語辭典修訂本》 (CC BY-ND 3.0 TW). The app converts the word to traditional characters to find it, and shows the entry as the dictionary has it, in traditional characters with Taiwan usage, because the licence doesn't allow changing it. The source is shown on each card.
  - Malay and Tamil words have no look-up yet. Meanings and example sentences can always be typed or pasted in by hand, and anything a look-up fills in can be changed.
- **Word cards:** click a word for its card: the word large, pinyin or pronunciation, 🔊 to hear it, the meaning and example sentences (🔊 reads a sentence), and ‹ › for the next word.
- **Dictation:** **Start dictation** reads each word aloud (once, twice or three times) while the screen shows only its number. **Again** reads it again, **Back** and **Next** move between words (or ← → and R for again). **Show answers** lists the words with their pinyin for marking; click one to hear it.
- **⚙️ Settings:** the voice for each language, speed, how many times each word is read, whether to wait for **Next** or move on by itself after 5–20 seconds, as listed or **shuffled**, and whether to read the first example sentence too (word · sentence · word).
- **Voices** come with the computer. Most have English; Chinese, Malay and Tamil voices can be added free (Windows: Settings → Time & language → Speech → Add voices). The tool says when a language has no voice and shows how to add one. Microsoft Edge's online natural voices (for Chinese, Malay, Tamil and Singapore English) sound best but need the internet.

## Character grid 汉字田字格

- Type one or more Chinese characters (up to 12); tap a character above the grid to show it. Its **pinyin**, **stroke count** and a **strip of every stroke** in order are shown.
- **Watch 演示:** **Play** draws the character stroke by stroke; **Loop** keeps playing it; **Stop**.
- **Step 分步:** **Next stroke** adds one stroke at a time, in red, over a pale outline (← → or the space bar work too). Click a box in the strip to jump to that stroke.
- **Trace 描写:** students write each stroke in order with a finger, stylus or mouse; a hint appears after two misses, and the tool says when the character is finished.
- Options: **田字格**, **米字格** or plain; speed; outline; **radical 部首** in orange (in Watch and Step); pinyin on or off.
- Stroke data covers about 9,500 characters (simplified and traditional). It is part of the app: a character's data (2–4 KB) downloads only the first time it is shown, then stays on the computer for offline use, separately from boards, so it doesn't use their space.

## Read aloud 朗读

For weaker readers: the passage is up in large type, and the part being read lights up word by word, so students can follow, repeat and read along.
- **Passages** are shared by every board in this browser, like Dictation word lists. Pick one at the top of the tool, or **+ New passage**. **Try the sample passages** adds two short ones written for the app (中文 and English). A passage's language (中文 or English) is taken from what is pasted in, and can be changed. Line breaks are kept as paragraphs.
- **Model reading 范读:** the computer reads the passage sentence by sentence while the current word is highlighted and the rest of the passage fades (this can be turned off). **Pause**, **Back** and **Next** move by sentence; clicking any part of the passage starts from there.
- **Echo reading 跟读:** the computer reads one part, then the screen shows *Your turn · 跟我读* for the class to repeat it. Parts are sentences or, for shorter pieces, **phrases** (split at ，、： and commas). The tool waits for **Next**, or goes on by itself after about as long as the part took to say, and a little more (a bar shows the time left).
- **Choral pacing 齐读:** no voice. After a *3 · 2 · 1* count-in, the highlight moves at a steady pace (**Slow**, **Steady** or **Brisk**: about 85, 115 or 155 Chinese characters a minute), with short pauses at commas and full stops. It works on computers with no voice for the language.
- **Tap to hear 点读:** tap a word to hear it, and see its pinyin above it if pinyin is hidden; or switch to **Sentence** to hear the sentence it is in.
- **Pinyin** (Chinese passages): **All**, **Chosen** or **Off**. With **Chosen**, **Choose characters** lets the teacher tap the characters that should keep their pinyin (new or difficult ones); the choice is saved with the passage. Pinyin is worked out in the app, so it works offline, in dictionary tones for 一 and 不 unless **spoken tones** is turned on in settings. When editing a passage, **Check the pinyin** underlines characters with more than one reading (行, 长, 着…); click one to choose its reading or type one in. Corrections and chosen characters follow the text when it is edited.
- **Keys:** space starts and pauses (in Echo reading, it goes on to the next part), ← → move between parts (presentation clickers work too), R says the current part again.
- **Voices** are the computer's own, the same ones Dictation uses (and the voice chosen for Dictation on this computer). Both tools pick the best voice by themselves: Microsoft Edge's natural voices in Edge, then Google's voices in Chrome, then other online voices, then the computer's own (online voices are skipped when the computer is offline). Cantonese voices are never used for 华文. Settings lists **Recommended** voices first and the rest under *Other voices on this computer*; Apple's novelty voices (Eddy, Flo, Grandma, Reed…), which recent Macs and iPads list first and which sound robotic, are marked *robotic* and come last. If a voice makes no sound (an error, nothing within 4 seconds, or "finishing" far too fast, as voices listed but not downloaded do), the tool says so and reads with the next good voice; **Test** in settings tries the voice exactly as chosen and says if it made no sound.
- **Keeping the highlight in step:** when the voice reports where it is, the highlight jumps there; between reports (some voices report only once a phrase in Chinese, and Google's online voices not at all) it moves on at the pace the voice has actually been reading, learnt from how long each part takes and kept in this browser (`xingtan:voicePace`). Chinese sentences longer than a short phrase are read a phrase at a time, so the highlight starts again in step at each phrase; this also stops some voices cutting out part-way through long sentences.
- Minimised, the chip shows play / pause and which part the class is on.

## Sentence analysis 层次分析

For demonstrating 层次分析 (immediate-constituent analysis) in front of the class, with the conventions of **庖丁**, the 层次分析 practice app: brackets under each part, the part's role under its bracket (主｜谓, 述｜宾, 定｜中…), and particles in grey.
- **The sentence:** type or paste a Chinese or English sentence or phrase. The language is worked out from what is typed and can be changed. Chinese is split into single characters (Latin letters and numbers stay together), English into words. 的、地、得、了、着 are greyed and kept with the word before them (虚词随前), except where they start a word (的确, 地方, 得到, 了解, 着急…); punctuation sticks to its word. Tap any word in the preview to grey it out or back. Changing the words clears the cuts; greying a word keeps them.
- **Cutting (Analyse):** the part being cut is shaded. Tap the gap where it divides (two or more gaps for 并列 or 连动), then choose the relation. The tool moves on to the next uncut part, top-down and left to right. To cut another part, tap its word or tap straight on one of its gaps; **‹ Previous part** / **Next part ›** (or ← →) step through the uncut parts in reading order. **Keep whole** marks a part that is one word (王平, 园艺家) so the tool skips it; tapping one of its gaps cuts it after all. Tap a bracket to change that cut's relation or **Remove this cut** (with every cut inside it). **Undo** goes back step by step. Escape clears gaps tapped but not yet labelled.
- **Labels:** the 庖丁 set: 主谓, 述宾, 述补, 定中, 状中, 中定 and 中状 (English modifiers after the head), 并列 and 连动 (any number of parts: 并｜列｜列), 介宾, 方位, 数量. **My labels** adds the teacher's own (such as 同位 or 兼语) with the names of their parts; they are shared by all boards and go into full backups. Each cut keeps its label's name and roles, so a shared board shows them even where the label isn't in the list.
- **Present:** replays the analysis from the bare sentence, one cut per **Next** (→, space or a presentation clicker; ← goes back), **As cut** or **Layer by layer**. With **Pause before labels**, each cut first appears with **?** under its parts so the class can name the relation; the next click (or clicking the **?**) shows it. **Show all** and **Start again** jump to the end or the start.
- The diagram grows or shrinks to fill the tool, up to large classroom type, so a big tool reads from the back of the room.
- Analyses are saved on the board as you go (see [Saved on this board](#saved-on-this-board-本白板已存)), named by their sentence. **Make a copy** opens the copy ready to present. Minimised, the chip shows the step and **Next**.

## Quotes 名言佳句

Sayings to put up as a holding screen while students come in, or to start a values discussion in CCE.

- **The 杏坛 library:** 163 quotes (109 Chinese, 54 English) about life, work and learning, each naming the work it comes from (《论语·为政》, *Walden*, a 1957 speech…). Chinese quotes are mostly classical (论语, 孟子, 荀子, 礼记, 老子, Tang and Song poems) with a few from Liang Qichao and Lu Xun. English quotes are from works in the public domain or are short quotations with a documented source. Well-known misattributions (the “Einstein”, “Confucius” and “Aristotle” sayings that they never said) are left out.
- **Tagged by value:** every quote carries one or two of the CCE core values, **R³ICH** (尊重 Respect, 责任感 Responsibility, 坚毅不屈 Resilience, 正直 Integrity, 关爱 Care, 和谐 Harmony). Filter by value, and by language (中英文 / 中文 / English).
- **Layers for Chinese quotes:** **pinyin** above the characters (拼音), the **modern Chinese meaning** (白话释义) and an **English translation**, each switched on or off from the bar on the tool (it appears when you hover) or in Settings. The source can be hidden too.
- **竖排:** Chinese quotes can run in vertical columns, right to left, one clause to a column, with the source in its own column; the gloss and translation sit to the left.
- **Changing quotes:** change by themselves every 10 s – 5 min (shuffled or in order), **stay on one** (← → choose), or **Quote of the day** (今日名言): the same quote all day on every board with the same settings (language, value, collection and skipped quotes), changing at midnight. ← → choose a quote and the space bar pauses or restarts the changing when the tool is selected. **Skip** (👁 crossed out) hides a quote from that tool; Settings brings skipped quotes back.
- **Look:** **Paper** (warm cream), **Ink** (dark) or **On the background**, which drops the card so the words sit over the board's picture with a soft shade behind them.
- **Thinking prompt:** an optional question under the quote, such as *What do you think this means? What makes you say that?* or *Which of our core values does this show?*, in English, 中文 or both, or your own question.
- **Holding screen:** one button lays the board out for the start of a lesson: the quote on the left, a **3-minute Timer** and the **Music** tool (set to *Play with the Timer*, with a calm track from the music library if its list is empty) on the right, and the dock hidden. Press **Start** on the Timer as students come in; the music starts with it and fades out at zero. Tools already on the board are moved, not added again.
- **My quote collections:** your own quotes, shared by all boards in this browser and included in backups. Paste one quote per line; from a spreadsheet, paste the columns as they are (Chinese: quote · source · English translation · 白话释义; English: quote · who · where). Chinese quotes get their pinyin automatically (check words with more than one reading). A shared board file carries a copy of the collections its Quotes tool shows, so a department can pass a collection round.
- Chinese quotes are set in a 楷体 (LXGW WenKai, cut down to the library's 656 characters, about 150 KB). Teachers' own quotes use the computer's own 楷体 (KaiTi on Windows, Kaiti SC on a Mac) so that every character matches.

## Privacy and data

- Data is saved in the browser's **IndexedDB** (database `xingtan`) on the device in use: one record per board (store `boards`, pen and highlighter marks included) and one for class lists, points, past poll results and settings (store `kv`, key `meta`). It is not shared between browsers or computers. IndexedDB can use a large share of the computer's free disk space, so heavily annotated boards don't run into the ~5 MB limit that `localStorage` has.
- **⚙️ → Storage on this computer** shows how much space the app uses and roughly how much the browser allows, split into boards and drawings, pictures and PDF pages, and class lists and points.
- **Moving from earlier versions:** versions before November 2026 saved boards in `localStorage` (`xingtan:v2:meta`, `xingtan:v2:board:<id>`, and before that `xingtan:v1`). The first time the new version opens, it copies everything into IndexedDB, checks the copy, and keeps the old entries for 30 days as a fallback before removing them. If a tab still running the older version saves a change in that time, the new version picks it up. If another tab is holding the database open while the update arrives, the app asks the teacher to close it and then carries on by itself.
- Changes are saved a moment after they're made. If a window closes before a save has finished, the app keeps an emergency copy in `localStorage` (`xingtan:v3:unsaved:<window>`) and saves it properly the next time it opens.
- If a browser won't open IndexedDB, the app keeps working with the older `localStorage` layout, and the storage panel says so.
- **⚙️ → Download backup** saves every board, class list, points log and past poll results to a `.json` file, with the chosen Dictation voices, pinned boards and how the boards screen is sorted and shown. **Restore from backup** loads it on another computer. Before it replaces anything, it shows what the backup holds and what is in the browser now. It warns if work here is newer than the backup, offers to back that up first, and needs a second click to go ahead.
- **Backup reminder:** once a week's work hasn't been backed up (or a week after first use, if there has never been a backup), the boards screen shows a reminder with **Download backup** and **Later** (hides it for three days). There is no reminder when nothing has changed since the last backup.
- Music files added to the Music tool are kept in the same database (store `audio`). Full backups include those in use; shared board files don't. A music file is deleted from the browser when no board uses it any more.
- Spotify playlists play in Spotify's own embedded player, which loads from Spotify when the teacher opens one; what plays there is between the browser and Spotify. The app also asks Spotify's public oEmbed service for the playlist's name when a link is pasted. Library tracks come from this site.
- Uploaded background images and Images-tool pictures are kept in the same IndexedDB database (store `images`). Full backups include every picture in use; shared board files include Images-tool pictures but not uploaded backgrounds.
- A YouTube search key, if one is added, is kept in its own entry (`xingtan:youtube`) in this browser only. It is never included in backups or shared board files. Searches and video playback go directly from the browser to YouTube.
- Clearing browser data removes everything, so keep a backup. In Chrome's *Delete browsing data*, **Cookies and other site data** (ticked by default) deletes the app's data; **Cached images and files** on its own is safe. Incognito and Guest windows forget everything when they close.
- Browsers may clear site data by themselves when the computer runs very low on disk space. The app asks the browser to keep its data (`navigator.storage.persist()`) once there is something to keep. Chrome and Edge decide quietly, and usually agree for installed apps and bookmarked sites; **⚙️** shows whether the browser has agreed.
- **Text** posts are kept with the class lists (store `kv`, key `meta`).
- **Dictation** word lists are kept with the class lists (store `kv`, key `meta`), and the voices chosen on this computer with them. Dictionary look-ups send only the word, and only when the teacher clicks **Look up**: English words to dictionaryapi.dev, Chinese words to moedict.tw.
- **Read aloud** passages, the characters chosen to show pinyin and pinyin corrections are kept with the class lists (store `kv`, key `meta`). They go into full backups, and a shared board file carries a copy of the passage its tool shows. The app sends nothing. Speech uses the browser's voices; online ones (Google's voices in Chrome, Microsoft Edge's natural voices) send the text to that company to be spoken, as they do for Dictation.
- **Sentence analysis** sentences and cuts are kept on the board; the teacher's own labels are kept with the class lists (store `kv`, key `meta`) and go into full backups. Nothing is sent anywhere.
- **Character grid** stroke data comes from this site (`data/hanzi/`) and is kept in its own offline cache (`xingtan-hanzi-v1`) from the first time each character is shown.
- The one exception to “nothing leaves the browser” is the optional [Google connection](#google-connection): when a teacher uses it, the thinking-routine and poll forms, students' answers and Sheets are kept in that teacher's own Google Drive.

After the first visit, a service worker keeps a copy of the app, so it works without internet.

**GitHub Pages:** Settings → Pages → *Deploy from a branch* → `main` / `(root)`.

## Adding a tool

1. Create `js/widgets/yourtool.js` exporting `{ type, title, icon, tone, size, minSize, mount(body, ctx) }`.
   `icon` is a name from `js/icons.js` (add its path data there from [Tabler Icons](https://tabler.io/icons) if it is new).
   `tone` is the tile colour: `time`, `people`, `signal`, `content` or `language`. New tools appear at the end of everyone's dock.
2. Register it in `js/widgets/index.js`.
3. Add the file to the `FILES` list in `sw.js` and bump `VERSION`.
4. Write its card for the user guide in `js/guide/` (see [js/guide/README.md](js/guide/README.md)), and add a line to *What's new* there.

`ctx` gives each tool `ctx.state` (its saved state, removed when the tool is closed), `ctx.save(patch)`, `ctx.boardData` / `ctx.saveBoardData(patch)` (kept on the board for that type of tool, so it survives closing the tool; never put student names here), `ctx.onBoardDataChange(fn)`, `ctx.store` (class lists), `ctx.onClassesChange(fn)`, `ctx.openClasses()` and `ctx.toast(msg)`.
Every tool gets a **−** button that shrinks it to a chip on the board; the tool stays mounted and keeps running (`minimize: false` turns this off). `ctx.setMiniControls(...nodes)` puts live controls on the chip (with none, it shows the tool's name), `ctx.setMiniLabel(text)` shows a short text in place of the name (it stays readable on the shelf), `ctx.minimized` tells whether it is minimised, and `ctx.onMinimize(fn)` calls `fn(true / false)` when it is minimised or opened again.
`mount` can return `{ destroy() }` to clean up timers or the microphone.
If a tool's state can hold student names, give it `share(state)` returning a copy without them. Shared board files use it.
If a tool must finish something when it is gone for good (for example stop a Google Form taking answers), give it `closed(state)`. It runs once the Undo after closing has run out (or the page closes first), and for each tool on a board that is deleted.
